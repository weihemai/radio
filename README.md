**My Car Web Radio**

Being frustrated about my China EV (ONVO L60 2024 model) only offering Chinese UI and no proper radio app covering international stations, I created this small car radio app with claude.ai (free version) for my car's built-in webbrowser featuring 

- station lookup from https://www.radio-browser.info/ 
- English / German language UI
- large, easy to operate touch UI elements
- auto-return to home screen after 20 sec no activity (while driving)
- dark / light mode toggle
- favourite stations
- Now Playing track information
- Clock showing the local time / small clock in the player showing the station's local time (aaprox. by station country)
- settings dialog with language, font size, source, dark mode etc.
- all settings stored in local browser storage

*Free to use and improve, but please quote the original source when forking.*
